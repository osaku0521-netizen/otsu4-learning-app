# 乙種第4類 危険物取扱者 合格マスター (乙4合格マスター)

消防試験研究センターの出題形式・過去問傾向に完全準拠した、乙種第4類危険物取扱者試験の総合Web学習プラットフォームです。
PC・タブレット・スマートフォンの全デバイスで、インストール不要・完全無料で利用できます。

- **本番サイト**: [https://otsu4-learning-app-seven.vercel.app/](https://otsu4-learning-app-seven.vercel.app/)
- **GitHubリポジトリ**: [https://github.com/osaku0521-netizen/otsu4-learning-app](https://github.com/osaku0521-netizen/otsu4-learning-app)

---

## 🌟 主な機能と特徴

### 1. 演習モード (一問一答・分野別演習)
- **充実の全420問収録（本番模試12回分相当）**:
  - 危険物に関する法令: **180問**
  - 基礎的な物理学及び基礎的な化学: **120問**
  - 危険物の性質並びにその火災予防及び消火の方法: **120問**
- **2つの演習サブモード搭載**:
  1. **5肢択一演習**: 本番と同一の5肢択一形式。選択肢の並び順が毎回自動でシャッフルされ、位置暗記を防止。
  2. **〇✕演習（全1,476問プール）**: 1文ごとの正誤をスピーディに見抜く論点定着演習。
     - **🎯【対象・前提】ブロック**: 設問の対象・文脈（例:「指定数量以上の危険物を運搬する車両に掲げる標識」等）を明示し、何を聞かれているのかが一目で把握可能。
     - **📌 論点テーマ表示**: 公式シラバス26項目に完全準拠し、省略（…）のない正確な論点名を表示。
     - **完全ランダム出題＆再シャッフル**: いつでも出題順を再生成可能。
- **柔軟なフィルタリング**:
  - 科目別フィルター（全科目 / 法令 / 物理化学 / 性質消火）
  - 頻出度フィルター（★★★ 超頻出 / ★★ 頻出 / ★ 重要）
  - 「未出題のみ」「間違えた問題のみ」「ブックマークのみ」の抽出演習
- **要点テキスト連動**:
  - 問題の解説下部にある「テキストを開く」ボタンから、該当する要点テキストの章へワンクリックでジャンプして復習可能。

---

### 2. 本番模擬試験モード
- **本番構成を完全再現（計35問）**:
  - 法令: 15問 / 物理化学: 10問 / 性質消火: 10問（全420問から毎回ランダム抽出）
- **120分カウントダウンタイマー**:
  - 残り時間10分未満で警告パルス表示。0秒到達で自動提出・採点。
- **35問ナビゲーターパレット**:
  - 解答済み・未解答・要見直しフラグを一目で把握。
- **本番合格判定ロジック**:
  - 3科目すべてで「正答率60%以上（法令9問、物理化学6問、性質消火6問）」を達成した場合のみ「合格」。1科目でも下回った場合は足切り科目を明示して「不合格」と判定。
- **履歴・学習進捗自動連携**:
  - 模試の解答履歴は自動保存され、間違えた問題は演習モードの「間違えた問題のみ」フィルターへ自動反映。

---

### 3. 要点テキスト（全14章）
- **公式シラバス全26項目を完全カバーする全14章**:
  - 第1編 法令（第1章〜第5章）: 定義・品名・指定数量、製造所等の区分・手続き、位置・構造・設備、消火・警報、保安体制・運搬移送
  - 第2編 物理化学（第1章〜第5章）: 燃焼理論、引火点・発火点・燃焼範囲、状態変化・熱力学、基礎化学・反応熱、静電気
  - 第3編 性質消火（第1章〜第4章）: 第4類の共通性状、特殊引火物・第1石油類・アルコール類、第2〜第4石油類・動植物油類、消火理論・消火剤
- **章別・過去問演習ダイレクト開始**:
  - 各章末尾の「✍️ この章の問題を解く（◯問）」ボタンから、読んだ直後に関連問題を演習可能。
- **数式カードコンポーネント**:
  - ボイル・シャルルの法則や指定数量の倍数計算などを視覚的にわかりやすくレイアウト。

---

### 4. 用語解説集（重要用語100選）
- **リアルタイム・インクリメンタル検索**:
  - 用語名、読みがな、解説文のキーワードで即時絞り込み。
- **科目別ワンタッチフィルター**:
  - 法令 / 物理化学 / 性質消火のタブ切り替え。

---

### 5. 学習進捗ダッシュボード
- **演習マスター状況**:
  - 5肢択一の消化率・正答率、科目別進捗バー、ブックマーク数。
  - 〇✕演習の消化問数・セッション正答率。
- **模擬試験履歴一覧**:
  - 受験日時、総合得点、各科目の正解数、合否判定をテーブル一覧で記録。

## 🔍 データ品質・妥当性検証

収録されている全420問および〇✕演習プールは、自動検証スクリプト（`scripts/verify_dataset.js`）により以下の品質基準を常時クリアしています：

1. **基本構造・フォーマット**: 全420問が5肢択一形式、有効な正解インデックス、10文字以上の解説を保有。
2. **非重複性**: 問題文および選択肢の完全重複ゼロ件。
3. **乙4出題範囲準拠**: 乙4の範囲外キーワード（他類、高圧ガス、ボイラー等）の混入ゼロ件。
4. **選択肢シャッフル整合性**: 「上記すべて」「1〜4は」等のシャッフル阻害表現ゼロ件。3,000回のシャッフルシミュレーションで正解追跡エラー率0.00%、各肢の正解均等度（約20%ずつ）を確認。
5. **〇✕演習の視認性・完全性**: 論点テーマの文字数切り捨て（…）ゼロ件、設問前提（文脈）の保持率100%。

※詳細な検証レポートは [VERIFICATION_REPORT.md](VERIFICATION_REPORT.md) をご覧ください。

# 危険物取扱者 乙種第4類 学習プラットフォーム (乙4合格マスター)

消防試験研究センターの出題形式・過去問傾向に準拠した、乙種第4類危険物取扱者試験の総合Web学習プラットフォームです。

---

## 🌟 主な機能と特徴

### 1. 一問一答式の練習問題パート
- **厳選全300問収録**: 法令130問、基礎的な物理学及び化学85問、危険物の性質並びにその火災予防及び消火の方法85問。
- **回答＋分かりやすい解説**: 正解の論拠だけでなく、誤答選択肢の誤り箇所や覚えるべき要点・語呂合わせを丁寧に解説。
- **過去の出題傾向から頻出度を表示**: 過去問出題頻度に基づき、各問題に【★★★ 超頻出】【★★☆ 頻出】【★☆☆ 基本】のバッジを表示。
- **ランダムシャッフル機能**:
  - **演習の出題順序シャッフル**: 毎回異なる順序で出題し、マンネリ化や順番暗記を防止。
  - **選択肢(1〜5)のランダム入替**: 肢の並び順が毎回自動で入れ替わり、正誤判定ロジックも追跡して正確に動作。
- **復習・ブックマーク機能**: 「間違えた問題のみ抽出」「ブックマークした問題のみ抽出」機能により、効率的な弱点克服が可能。

### 2. 本番を想定した模擬試験パート
- **消防試験研究センターの本番構成を忠実再現**:
  - 法令: 15問
  - 物理・化学: 10問
  - 性質・消火: 10問
  - 合計: 35問 (300問のプールからランダム抽出)
- **120分カウントダウンタイマー**: 残り10分で警告パルス点滅。
- **35問ナビゲーターパレット**: 回答済み、未回答、見直しフラグをひと目で把握。
- **本番合格判定ロジック**: 3科目すべてで「正答率60％以上（法令9問以上、物化6問以上、性消6問以上）」を達成した場合のみ「合格」。1科目でも下回った場合は足切り科目を明示して「不合格」と判定。
- **全問解答解説レビュー**: 受験後、全問の正誤・解説と弱点分野を一括確認。

### 3. テキスト＆用語解説のパート
- **体系的要点テキスト**:
  - 第1編: 危険物に関する法令（指定数量一覧表、保安距離・保有空地、保安監督者、セルフスタンド等）
  - 第2編: 基礎的な物理学及び化学（燃焼理論、引火点・発火点、消火理論、自然発火機構、ヘスの法則、静電気）
  - 第3編: 危険物の性質・火災予防・消火法（共通性状、特殊引火物、第1〜第4石油類、アルコール、動植物油類とヨウ素価）
- **検索機能付き用語解説集**:
  - 100+の重要専門用語を五十音・キーワード・科目別で即時インクリメンタル検索。
  - 試験対策ワンポイントアドバイス付き。

### 4. 学習進捗・統計ダッシュボード
- 消化進捗率、累計正答率、科目別マスター度プログレスバー。
- 過去の模擬試験の合否履歴をLocalStorageで自動保存。

## 🚀 起動方法

### ローカルサーバーで起動する場合 (推奨)
```bash
# プロジェクトフォルダへ移動
cd C:\Users\Takuro\.gemini\antigravity\scratch\otsu4-learning-app

# ローカルサーバー起動
node scripts/local_server.js
```
ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

### 直接ブラウザで開く場合
`index.html` を任意のブラウザ（Chrome, Edge, Firefox等）でダブルクリックして直接開くことも可能です（追加のビルドツールや外部サーバーは不要です）。
